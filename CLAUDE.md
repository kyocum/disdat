# disdat

Core data-versioning library. Bundles, HyperFrames, and the per-context local
index. Pipeline execution (Luigi, `apply`, `PipeTask`) and container builds
(the dockerizer) live in a separate repo, `kyocum/disdat-luigi` — they are not
part of this codebase.

## Toolchain

Use `uv` and run everything through the project environment (`uv run --extra
dev ...`). Never install into a system Python. For the test command itself, see
the commit gate at the bottom of this file.

The local per-context index uses Python's stdlib `sqlite3` directly. There is no
SQLAlchemy dependency; do not reintroduce one.

`disdat/version.py` is generated by `setuptools_scm` from git tags — do not edit
it by hand. `uv.lock` is gitignored.

## Branch and PR conventions

The default branch is `master`. Plan work lands as one `plan/<id>/phase-<n>`
branch and one PR per phase, tracked in `docs/superpowers/plans/PLAN_LOG.md`.

`origin` is public `github.com`. Pushes, PRs, and merges are performed by the
repository owner, not by an agent.
